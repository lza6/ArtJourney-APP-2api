## 2. 网络层全量还原

### 2.1 唯一业务域名

```
http://imageai.sboomtools.net          ← 明文 HTTP（PhotoNetwork.endPointApi()）
```

其余域名全部是广告/分析 SDK（AppLovin、AppsFlyer、OneSignal、AdMob、Facebook）。

### 2.2 端点清单（`com.example.photoapp.manager.network.PhotoNetwork`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v5/art` | 文生图 / 图生图（multipart） |
| POST | `/api/sketch` | 草图生图（multipart，`original_image` 必填） |
| POST | `/api/art/{id}/fetch` | 轮询生成结果 |
| GET | `/api/v3/home?page=N` | 首页：`styles[]` + `popular_arts` |
| GET | `/api/blogs?page=N` | 博客列表 |
| GET | `/api/blog/{id}` | 博客详情 |
| POST | `{url_gen}`（绝对 URL） | 图生文/提示词生成（来自 Firebase Remote Config） |

`/api/v5/art` 与 `/api/sketch` 的 multipart 字段：

| 字段 | 类型 | 必填 | 备注 |
|---|---|---|---|
| `prompt` | text | 是 | 提示词 |
| `ratio` | text | 是 | 客户端取值域：`1:1` / `2:3` / `3:2` |
| `style` | text | 是 | 来自 `styles[].model`（如 `anime-v1`） |
| `seed_id` | text | 否 | 可选 |
| `original_image` | file | 图生图必填 | 文件名即上传名 |
| `steps` | text | 否 | 可选 |
| `cfg_scale` | text | 否 | 可选 |
| `negative_prompt` | text | 否 | 可选 |

HTTP header：`signature: <hex>`（仅 `/api/v5/art`、`/api/sketch` 携带）。
超时：connect/call/read 全部 60s。

### 2.3 响应 schema（Gson 模型反推）

```
DataArt  { code:Int, status:String, art:Art }
Art      { id, status, image, temp_image, prompt, ratio, style,
           styleName, styleImage, seed_id, count_down, haveBannedWord }
Data     { code:Int, status:String, styles:[Style], popular_arts:{ items:[Prompt], pagination:{...} } }
Style    { name, model, prompt, image, description, is_vip }
Prompt   { id, image, prompt, ratio, style }
TextGenerated { prompt }
```

- `art.status == 1` 且 `art.image` 非空 → 出图完成；`art.count_down` 为客户端倒计时秒数。
- `art.haveBannedWord == 1` → 提示词命中内容过滤。

### 2.4 签名算法（核心）

位置：`w0.g.d()`（拼串）+ `w0.g.c()`（HMAC）。

```text
canonical = "prompt=" + prompt + "&"
          + "ratio="  + ratio  + "&"
          + "style="  + style  + "&"
          + ["seed_id="        + v + "&"]   # null 则整段省略
          + ["steps="          + v + "&"]
          + ["cfg_scale="      + v + "&"]
          + ["negative_prompt="+ v + "&"]
signature = hex_lower(HMAC_SHA256(key = RTDB密钥, msg = canonical 去掉尾部 "&"))
```

**三个容易踩的坑（都是原码行为，不是我的推断）**：

1. 每个片段都带尾 `&`，串一定以 `&` 结尾；代码里若检测到结尾不是 `&` 会 *直接返回空签名*。
2. 取 `lastIndexOf("&", lastIndex)` 再拼回去 —— 等价于**去掉尾部一个 `&`** 后才参与 HMAC。
3. 可选参数为 `null` 时**整段不拼接**（不是拼空值）；若传空串会变成 `steps=&`，签名与行为都不同。

**密钥来源**（本节是最有价值的一条）：`com.example.photoapp.utils.n.f6149a`
来自 Firebase Realtime Database `key_hash_hmac/key`，初始化为
`FirebaseDatabase.getInstance().getReference("key_hash_hmac/key")`。
实测该节点**匿名可读**，无需登录、无需 App Check、无需 API key：

```bash
curl -s https://imageai-d865e-default-rtdb.firebaseio.com/key_hash_hmac/key.json
# "d36cc0e575597ad822a76db7e4a89f3c"
```

也就是说：**签名密钥是公开分发的**，服务端校验形同虚设（任何第三方都能构造合法请求）。
密钥可被开发者在 RTDB 侧随时轮换 → 生产环境应实现定时拉取（`app/sign.py::fetch_remote_key`）。

> 坑位：国内网络**直连 firebaseio.com 会被 reset**（实测 `curl -sk --noproxy '*'` → 000），
> 必须走本地代理；`firebaseremoteconfig.googleapis.com` 同理。脚本里 httpx 默认读环境代理，直接用即可。

交叉校验：`tests/Sign.java` 按 Kotlin 语义逐行复刻，Python 与 Java 在 4 组向量（含中文、emoji、
含 `&` 的 negative_prompt）上逐字节一致 —— `tests/test_sign.py::test_matches_java_replica` 通过。

## 4. 存活判定（为什么这轮只能跑 mock）

| 目标 | 结果 | 命令/证据 |
|---|---|---|
| `https://imageai.sboomtools.net/` 及 20+ 业务路径 | **502**（nginx/1.18.0 Ubuntu，upstream 已挂） | `curl -sk -o /dev/null -w "%{http_code}"` 逐路径实测；直连（绕本地代理）与经代理结果一致 |
| `http://imageai.sboomtools.net/*` | 301 → https → 502 | 同上 |
| 该 IP 其他端口 | 8000 = 无关服务（`"Diary AI"` FastAPI）、5000 = 无关 Flask 面板 | `openapi.json` 实测 |
| Play 商店 | **404（已下架）**，同开发者 `newway.ai.avatar.maker.art.photo` 也 404；对照 `com.whatsapp` = 200 | Play 页面抓取 |
| `url_gen`（RunPod） | **404**（pod 已终止） | 经代理请求 `/generate-prompts` 返回 404、0 字节 |
| `*.sboomtools.net` 其他子域（CT 日志 16 条） | `anime` / `sketch` / `cms-sketch` 等是 Laravel 站点，`/api/v3/home` 无该路由；`imageai` 自身 502 | `certspotter` + 逐域探测 |
| Firebase RTDB / Remote Config | **存活**（Google 侧托管，与开发者服务无关） | 200 + 有效 payload |
| 本地 58 个历史 APK 模板扫描 | 只有 ArtJourney 使用该模板（`com/example/photoapp` + `PhotoNetwork` + `sboomtools`）；Glovy/kreivo 的 `api/v5/art` 属 Apero 家族，非同源 | `scan_siblings.py` 全量 dex 扫描，无第二例 |

**判定**：开发者停运——App 下架、API 主机 upstream 摘除、RunPod pod 回收，仅剩 Google 托管的配置面。
所以本轮 demo/压测全部跑在**严格按 schema 复刻的 mock** 上，等上游恢复只要 `ARTJOURNEY_MODE=real` 一行切换。
